# Task Board API

Welcome to "TaskBoard". This project is an api for task board. The project implements the main functions necessary for task board.

## Table of Contents

- [Features](#features)
- [Technologies Used](#technologies-used)
- [License](#license)

## Features

- **Project Management**: Get, create, edit and delete projects.
- **Tasks Management**: Get, create, edit and delete Tasks.
- **Registration and authentication**: create user and login to system.
